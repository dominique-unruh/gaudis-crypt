    EasyCrypt's pseudo-random permutations (theories/crypto/PRP.eca) #

    The abstract type D and the operator dD are Lean parameters, so EasyCrypt's clone PRP with type D <- … and clone RP with op dD <- … are applications. So are the module variables (RP.m, RP.mi): a clone declares its own global_vars and passes them. The sub-theories StrongPRP and RP are namespaces. Only what ported developments use is here (WeakPRP is not).
