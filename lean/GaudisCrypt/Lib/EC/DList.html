    EasyCrypt's list distributions (theories/distributions/DList.ec) #

    dlist d n samples n values from d, independently. The abstract theory Program's type t and operator d are section variables, so a clone is an application. Only what ported developments use is here.

        The body of proc sample of module LoopSnoc, as a procedure of its own: it calls no module parameter, so it has no holes.

        A hole stands for a call whose callee is not known here — a module parameter is supplied only when the module is applied — so the body is a ProcedureWithHoles, to be instantiated (see LoopSnoc.sample.procedure.apply_simp) rather than run. Use LoopSnoc.sample for this procedure as a module.
