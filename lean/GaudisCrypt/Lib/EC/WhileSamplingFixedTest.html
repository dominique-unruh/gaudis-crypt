    EasyCrypt's WhileSamplingFixedTest (theories/distributions/Dexcepted.ec) #

    Sampling from dt i \ test i (the distribution dt i conditioned on failing test i) and rejection sampling: SampleE samples the conditioned distribution, SampleWi resamples from dt i while the test holds. The theory's types and operators (type input, t, op dt : input -> t distr, op test : input -> t -> bool) are the class Params.

    Only what ported developments use is here: the modules SampleE, SampleWi, and the lemmas pr_sampleE, pr_sampleWi, sampleE_sampleWi. The proofs are not EasyCrypt's (which go through its theories TwoStepSampling and WhileSampling): pr_sampleWi is the loop rule while I V k ε with the two-step identity dexcepted_indirect for the body. Names are EasyCrypt's.

    theorem GaudisCrypt.EC.dexcepted_expected_step {α : Type} (d : SubProbability α) (X P : α → Prop) (hd : is_lossless d) :
    (d.expected fun (a : α) => ENNReal.ofReal (if X a then mu (dexcepted d X) P else if P a then 1 else 0)) = ENNReal.ofReal (mu (dexcepted d X) P)

    One round of rejection sampling: the expected value, over a draw from d, of "the probability of P under d \ X if the draw is in X, else whether the draw is in P", is the probability of P under d \ X (EC's TwoStepSampling, dexcepted_indirect).
