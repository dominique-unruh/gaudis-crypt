    Random oracles (EasyCrypt theories/crypto/ROM.eca) #

    The module types of an oracle and the lazy random oracle Lazy.LRO, with its losslessness. (FiniteEager, and the equivalences between the lazy and the eager oracle, are not ported: Lib/EC/PROM.lean has EC's programmable oracles and their lazy/eager theory.)

    The theory's types in_t, out_t, d_in_t, d_out_t are outParams of the class Params, its operator dout the class's field: a clone is clone import GaudisCrypt.EC.ROM as H with type in_t <- …, op dout <- …. The module variable LRO.m is a module_var.
