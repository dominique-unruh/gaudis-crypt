    EasyCrypt's PRP/PRF switching lemma (theories/crypto/prp_prf/Strong_RP_RF.eca) #

    The abstract theory's types D, K and operators uD, dK, q are section variables (with their axioms as hypotheses where used), so a clone is an application. Only what ported developments use is here: ARP, DBounder and the statement of Conclusion.

    The PRPi clone (clone import RP as PRPi with op dD <- uD rename "RP" as "PRPi") is PRP.RP.RP D uD. Module variables (PRPi.m, ARP.coll …) are parameters: a clone of this theory declares its own global_vars and passes them.
