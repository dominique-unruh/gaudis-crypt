    EasyCrypt's FixedBiased (theories/distributions/DBool.ec) #

    The biased coin of a fixed bias: the theory's op p : {real | 0%r < p < 1%r} as in01_p is the class Params, dbiased the distribution that gives true with probability p. A clone gives the bias (clone import GaudisCrypt.EC.FixedBiased as Biased with op p <- p). Names are EasyCrypt's.
