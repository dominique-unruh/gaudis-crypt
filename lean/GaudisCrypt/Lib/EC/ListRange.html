    range lemmas of EasyCrypt's List.ec #

    range m n (GaudisCrypt.EC.range) grows by one at the right (rangeSr), is empty when n <= m (range_geq), and its members are the integers in [m, n) (mem_range). Kept apart from List.lean so that its many importers need not be rebuilt.

    theorem GaudisCrypt.EC.range_geq (m n : ℤ) (h : n ≤ m) :
    range m n = []

    lemma range_geq (m n : int) : n <= m => range m n = [].

    theorem GaudisCrypt.EC.rangeSr (m n : ℤ) (h : m ≤ n) :

    theorem GaudisCrypt.EC.mem_range (m n i : ℤ) :
    i ∈ range m n ↔ m ≤ i ∧ i < n
