    EasyCrypt's Bigop (theories/algebra/Bigop.eca) #

    The big operator of a commutative monoid over a list: big P F r is the monoid's sum of F x over the x of r that satisfy P. The theory's type t with EC's Monoid cloned as Support (idm, +, addmA, addmC, add0m) is the class Params t; a clone gives the monoid (clone import GaudisCrypt.EC.Bigop as BBS with type t <- word, op idm <- zerow, op add <- xorw). Only what ported developments use is here. Names are EasyCrypt's.

    The theory's parameters: a commutative monoid on t (EC's clone export Monoid as Support).

    • idm : t

      Support.idm: the neutral element.

    • add : t → t → t

      Support.(+): the monoid's operation.

    • addmA (x y z : t) : add x (add y z) = add (add x y) z

      axiom addmA : associative (+).

    • addmC (x y : t) : add x y = add y x

      axiom addmC : commutative (+).

    • add0m (x : t) : add idm x = x

      axiom add0m : left_id idm (+).
