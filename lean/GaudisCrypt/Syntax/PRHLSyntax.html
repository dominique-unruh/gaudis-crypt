    Concrete syntax for relational judgments (pRHL) #

    EasyCrypt's equiv judgments, in the two forms of hoare[ … ] (Syntax/HoareSyntax.lean):

    equiv[ P ==> Q ] { var x : X; … } ~ { var y : Y; … }     -- prhlStmt, about two statements
equiv[ M₁ (x) ~ M₂ (y) : P ==> Q ]                       -- prhlProc, about two procedures

    The conditions are about two states, and every read says which: §x{1} reads x in the left state, §x{2} in the right one (EC's x{1}, x{2}); ={x, y} is §x{1} = §x{2} ∧ §y{1} = §y{2} (EC's ={x, y}). A read without a side (§x, $x) is an error in a relational condition.

    In the statement form, each side may declare its local variables; a condition sees those of both sides (a name declared on both sides must have the same type there). In the procedure form, the precondition sees each side's parameters and globals, the postcondition each side's result res and globals: §res{1} = §res{2}, §x{1} for the left parameter x. As for hoare[ M (x) : … ], the parameter names may be left out when they are recorded.

    The sided reads are expanded when the condition is elaborated: §x{1} becomes @eval _ _ _ (CurrentState.mk σ₁) x, a read at the left state σ₁ the condition is a function of — the read §x of a hoare[ ] condition, at a given state. So the reads are what the unary tactics already handle (simpReads, generalizeReads). (No printer yet: a relational judgment prints as the plain term.)

                  Printing #

                  prhlStmt A c₁ c₂ B prints as equiv[ P ==> Q ] { … } ~ { … } when both statements print as statements and both conditions are functions of the two states that only read them: a read §x at the left state (eval at CurrentState.mk σ₁, x.get σ₁, g.get σ₁.globals for a global g) prints as §x{1}, at the right state as §x{2}. Otherwise the judgment prints as the plain term. The reads are first replaced by relRead σ i x (the read, carrying its side), which the unexpander prints as §x{i}; the variables are recovered over the two statements and the two conditions together, each declared on the side whose statement uses it (the left one if only the conditions do).
