    structure GaudisCrypt.PrSyntaxTest.Coin.Structure :
    Type 1

    The record of the fields of a module of type Coin: the fields flip, pick, neg, one per moduletype field, each of that field's own module type.

    Coin.mk turns such a record into a Coin, Coin.structure turns a Coin back into one.

    • flip : procmod () → Bool
    • pick : procmod (ℤ, ℤ) → ℤ
    • neg : procmod (ℤ) → ℤ
