    Concrete syntax for probabilities #

    EasyCrypt's Pr[ M.f(a₁, …, aₙ) @ &m : E ]:

    Pr[ M (a₁, …, aₙ) @ &m : E ]

    is the probability that the procedure M, run on the arguments a₁, …, aₙ from the globals m : VariableAssignment, ends with a result and globals satisfying the event E — the real number (Procedure.Pr p (a₁, …, aₙ) m E : ℝ) (Logic/PHoare.lean). As in EC it is a real, so that differences and absolute values of probabilities are what they look like.

    • The subject M is what the procedure judgments take (hoare[ M : … ], phoare[ M : … ]): a procedure, or a procedure module (a module's X.f, Module.app X A, …), at term:max.
    • The arguments are Lean terms, as many as the procedure has parameters (none: M ()). A single term for a procedure with several parameters is the whole argument tuple.
    • The memory m follows & (EC's memory names), at term:max.
    • The event E is read like the postcondition of phoare[ M : … ]: §res is the result, §x a global, §allGlobals the whole global state. A Bool event is coerced, so EC's : res is : §res.

    It prints back in the same form (#roundtrip, PrSyntaxTest.lean).
