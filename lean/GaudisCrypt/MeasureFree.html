    class GaudisCrypt.MeasureFree (α : Type u_1) :
    Prop

    A type α is measure-free (Fremlin 438A: "measure-free" / "of measure zero", there stated for cardinals) if every probability measure on α defined on all subsets of α (i.e., w.r.t. the discrete σ-algebra ⊤) gives positive mass to some singleton.

    • exists_pos_singleton (μ : MeasureTheory.Measure α) [MeasureTheory.IsProbabilityMeasure μ] : ∃ (x : α), 0 < μ {x}
