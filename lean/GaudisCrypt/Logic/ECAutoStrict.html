    EC's auto on the strict skip #

    ec_auto     -- EC's `auto` on a Hoare triple, a `phoare` judgment or a relational judgment;
            -- on a goal about values, `ec_close` (`Logic/ECProgress.lean`)

    wp over the code from the end (on a relational judgment also rnd on the samplings, as equiv_auto); when the code is used up, ec_skip (Logic/ReadNorm.lean): the implication in read normal form, every read a value, an error if a state survives; then what EC's auto closes by itself. When the code is not used up (a call, a loop), the judgment is left there, as hoare_auto/phoare_auto/equiv_auto leave it.

    The difference to those three: one normalizer on every path, and no goal silently left about the states. They are unchanged; proofs move to ec_auto one file at a time (notes/SHA3/TacticReview.md, step 3).
