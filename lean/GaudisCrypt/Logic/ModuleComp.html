    Applying a composite functor module #

    Module.comp f g is EasyCrypt's alias module F (X) = f(g(X)); applied, it is the nested application (one β-step of the module calculus).

    source
    theorem GaudisCrypt.Module.app_comp {A B C : Type 1} [IsModule A] [IsModule B] [IsModule C] (f : Arr B C) (g : Arr A B) (x : A) :
    app (comp f g) x = app f (app g x)

    Module.comp f g applied to x is f applied to g x.
