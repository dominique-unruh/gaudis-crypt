    EasyCrypt's transitivity #

    equiv_trans{i} { code } (P₁ ==> Q₁) (P₂ ==> Q₂)     -- EC's `transitivity{i} { code } …`

    On a relational judgment c₁ ~ c₂ : P ==> Q: through the middle code code (written over side i's variables, more declared with var), the judgments c₁ ~ code : P₁ ==> Q₁ and code ~ c₂ : P₂ ==> Q₂. Goals in EC's order: the precondition splits through a middle state (∀ σ₁ σ₂, P σ₁ σ₂ → ∃ σ, P₁ σ₁ σ ∧ P₂ σ σ₂), the postconditions compose (∀ τ₁ τ τ₂, Q₁ τ₁ τ → Q₂ τ τ₂ → Q τ₁ τ₂), then the two judgments. The rule is prhlStmt.trans (Logic/LoopTransform.lean), by the gluing of couplings.

    For procedures, prhlProc_trans_ec: the same through a middle procedure (EC's transitivity N (P₁ ==> Q₁) (P₂ ==> Q₂)).
