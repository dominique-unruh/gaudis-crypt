    Golden tests of stmt_split_params #

    The code EC's inline leaves: one assignment per parameter of an inlined call, the result's tuple assignment as it is (see Logic/ECAutoTest.lean for the format; scripts/update_golden.py refreshes the expected text).

    noncomputable def GaudisCrypt.ECInlineParamsTest.M :
    Module.Prod (procmod (ℕ, ℕ, ℕ) → (ℕ × ℕ)) (procmod (ℕ) → ℕ)

    The module declared by module M: the record of its procedures M.add, M.main.

    The declaration has no parameter list, so no procedure of it can call one either and the module is not a function — it is the plain record itself, and there is no M.apply_simp to apply it with.
