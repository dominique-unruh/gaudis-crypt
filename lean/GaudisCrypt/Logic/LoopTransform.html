    Loop transformations and statement-level transitivity #

    EasyCrypt rewrites loops in a relational judgment before reasoning about them: splitwhile{i} k : e (a loop while c b becomes while (c /\ e) b; while c b) and unroll{i} k (one iteration peeled off as a conditional). Here both are denotational equivalences of statements (StmtWithHoles.Equiv), moved into a judgment with prhlStmt_of_equiv_left/_right.

    splitwhile is proven for loops whose first part terminates by a variant (every SHA-3 loop is bounded): the remaining loop's expectation is then a fixed point of the first part's loop, from above (Stmt.ewp_while_le) and from below (Stmt.ewp_while_ge_variant).

    EasyCrypt's transitivity{i} { code } P Q at the statement level is prhlStmt.trans.
