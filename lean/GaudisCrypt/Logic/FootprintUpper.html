    Upper bounds of footprints #

    fp_disjoint proves restrictions FVP.fvP M ≤ Aᶜ. fp_le proves upper bounds FVP.fvP M ≤ U, U a join of variables and module footprints (EasyCrypt's "the module only touches these variables", read off the code): the same descent through the module combinators (fvP_app, fvP_pair, fvP_fst, …, unfolding definitions) down to concrete modules with an @[fp_bound] bound, or modules with a bound hypothesis FVP.fvP N ≤ B in context, and B's joinands found among U's (FootprintSolver.solveLeSup). A concrete module or a module's procedure with no stated bound has the one read off its code (ModuleFootprint.cachedBound, as fp_disjoint does). A use: the frame rule prhlProc_frame_equal_outside, whose callees must stay within a lens.
