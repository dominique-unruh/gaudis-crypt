    Footprint disjointness from module restrictions #

    EasyCrypt checks {-M}-style side conditions itself: a variable lies outside a module's globals when the module is built from modules whose restrictions exclude it. Here such a side condition is a goal A ≤ (FVP.fvP M)ᶜ (equivalently FVP.fvP M ≤ Aᶜ), and fp_disjoint proves it the same way: it bounds FVP.fvP M through the module combinators (fvP_app, fvP_pair, fvP_fst, …, unfolding definitions such as a module type's accessors and constructors) down to modules with a restriction hypothesis FVP.fvP N ≤ Sᶜ (or a declared module Module.Declared N S, Logic/DeclareModule.lean) in the context, and finds A among the joinands of S (a joinand glob X, EasyCrypt's restriction against an abstract module, covers A ≤ X).

    A concrete module has no restriction hypothesis: its globals are read off its code. A lemma FVP.fvP M ≤ B tagged @[fp_bound] (proven by fp_module) bounds it; B is then a join of variables. A variable v is outside glob D when it is outside D and D is finitely supported (EasyCrypt's glob D is a set of variables): Footprint.varLens_le_compl_glob, with the finite support from a hypothesis Module.ECModule D _ (or (FVP.fvP D).FinitelySupported). A restriction between abstract modules is symmetric (Footprint.le_compl_glob_symm): M is outside glob D when D is outside glob M.

    A region R given for a module in place of its glob (Footprint.Restricted R S: R stays outside S; Logic/DeclareModule.lean, declare module … with glob R) is read like a restriction hypothesis R ≤ Sᶜ: a variable or an abstract module among the joinands of S is outside R.

      class GaudisCrypt.Footprint.Restricted (R S : Footprint VariableAssignment) :
      Prop

      A region restricted against S: R, finitely supported, stays outside S. The region given for a module in place of its glob (declare module D <: T {-…} with glob R, Logic/DeclareModule.lean): where a lemma about a declared module D restricts other modules against glob D (EC's forall (F <: T {-D})) and is applied to a module built from a declared one, glob D of the application is known only from above; the lemma is stated against a region R above D's footprint instead, which the application gives explicitly (EC's glob F(A): glob F and glob A). fp_disjoint reads it as the hypothesis R ≤ Sᶜ.
