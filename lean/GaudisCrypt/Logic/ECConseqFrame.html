    EasyCrypt's conseq keeps what the code does not modify #

    EC's conseq (_: P' ==> Q') on c₁ ~ c₂ : P ==> Q asks P => P' and forall &1 &2, P => forall (modified variables), Q' => Q: the variables the code does not write keep their values from the precondition. Here that is a frame on each side (prhlStmt_conseq_frame): the variables Q reads whose writes the code commutes with (Stmt.CommutesWith, shown as for stmt_swap; such code keeps them, Stmt.satisfies_keep) keep their values from the start, and the side goal is ∀ σ₁ σ₂, P σ₁ σ₂ → ∀ τ₁ τ₂, (frames) → Q' τ₁ τ₂ → Q τ₁ τ₂. equiv_conseq (: P ==> Q) on statements is this rule (Logic/ECConseq.lean).
