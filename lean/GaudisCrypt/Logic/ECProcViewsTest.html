    Golden tests: a module read at another module type; a procedure's footprint read off its code #

    • equiv_proc and stmt_inline open a procedure of a module read through a view at another module type (EasyCrypt's subtyping: a primitive handed on as the distinguisher's view of it), with no module_norm first (Flatten.unfoldProcedure retries through the views where the plain pass finds no body; the SHA-3 port's LowerDist and Sponge(PRIMITIVE.view Perm) are the cases the plain pass misses).
    • fp_le bounds a module's procedure that has no stated @[fp_bound] by its code (ModuleFootprint.cachedBound).
