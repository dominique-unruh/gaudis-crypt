    EasyCrypt's alias #

    stmt_alias{i} n x = e      -- EC's `alias{i} n x = e`

    Before EC's statement n of side i (from 1, the resets inlining leaves not counted), the assignment x <- e to a fresh local x: it records e there, for the conditions after. The judgment about the code with the assignment gives the one without (prhlStmt_alias_left/_right): the code does not touch x (it commutes with every write to x, shown as for stmt_swap), and the postcondition does not read x on that side (a goal when simp cannot show it). x's type is e's.

    Running s₁; x <- e; s₂ and putting x back to its value at the start is running s₁; s₂, when neither touches x.
