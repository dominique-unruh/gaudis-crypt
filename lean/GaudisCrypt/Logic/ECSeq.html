    EasyCrypt's seq n m : P on a relational judgment #

    equiv_seq n m : P        -- EC's `seq n m : P`

    Cut both statements after their first n (left) and m (right) statements, in EC's positions (the resets inlining leaves are not counted: each goes with the statement after it, as for stmt_swap [a..b] k), with the relation P in between. Goals: the code before the cut (to P), then the code after it (from P). It is equiv_seq_last (Logic/PRHLWp.lean), which counts the statements after the cut, from the end.
