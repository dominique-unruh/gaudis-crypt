    Reads through the inliner's renamings of the locals #

    Inlining runs the inlined code on the locals renamed (Flatten.trafo: the caller's names, @… escaped; Flatten.rename ren: the cleanup permutation), and a condition about the state before it comes back as a condition about the renamed state, L.get σ. A read of a local n the renaming keeps (ι n = n, computed: no @ at the start, not among ren's names) is the read of n itself (localVarLens_get_mapLocal_embed_of_fix); a global's read is unchanged (globals_trafo_get, globals_rename_get).
