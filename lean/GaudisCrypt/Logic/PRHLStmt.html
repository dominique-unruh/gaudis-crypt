    pRHL for statements and procedures #

    The relational judgment on the statements and procedures of the language, EasyCrypt's equiv [ c₁ ~ c₂ : P ==> Q ]: from any two states related by P, the two runs can be coupled so that the final states are related by Q. It is the coupling judgment ProgramDenotation.prhl2 (Logic/PRHL2.lean) at the statements' denotations, so all its rules apply; this file states the ones the tactics use at the level of statements:

    • sequencing (prhlStmt_seq), skip, consequence, case analysis;
    • one-sided tails (prhlStmt_seq_left/_right): a statement run on one side only, which must terminate there — deterministic code (Stmt.Det) and lossless samplings are the instances the wp driver uses;
    • a sampling on both sides, coupled along a function (prhlStmt_seq_sample, EC's rnd f);
    • the synchronized loop rule (prhlStmt_while);
    • transport along statement equivalences, on either side (what stmt_inline/stmt_split use);
    • procedures (prhlProc), the bridge to the statement form, and EC's byequiv (Procedure.Pr_eq_of_prhlProc).

        One-sided tails #

        A statement at the end of one side only, matched against nothing on the other: it must terminate (the other side does nothing, so the coupling has to pair every run of it with the other side's final state), and the postcondition must hold on all its outcomes. Deterministic code and lossless samplings are the instances; EC's wp and rnd{1}.
