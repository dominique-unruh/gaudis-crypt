    felInner

    EasyCrypt's fel over a procedure the oracles call #

    fel cntr step q bad [M : pre] inv?

    EC's fel names, between brackets, the procedures whose calls may set the failure event bad. They need not be the adversary's oracles: Gcol.eca's Pr_col names Gcol.sample_c, which the oracles S.f, S.fi, M.f call. EC then checks the rest of the oracles' code syntactically: it must not touch the counter and bad other than through the named procedures.

    Here (phoareStmt_fel_inner): the named procedure has EC's premises (FelProc, as FelOracle with pre a condition on all the globals — it may read what the oracles write), from which its calls do not increase fel's potential (FelProc.ewp_le); every oracle satisfies the syntactic check StmtWithHoles.ExpDecr for that potential (its writes keep the view of the counter, bad and inv; its calls are to the named procedure or check again), which exp_decr discharges.

    EC's premises of fel for a procedure p named in [p : pre], over the view L.get of the globals; pre a condition on the globals themselves (FelOracle with pre read through L).

    • lt (g : VariableAssignment) : inv (L.get g) → ¬bad (L.get g) → pre g → cntr (L.get g) < q

      a call that may set bad is one of the q the bound pays for

    • step : phoareProc (fun (x : sig.ParamType) (g : VariableAssignment) => inv (L.get g) ∧ ¬bad (L.get g) ∧ pre g) p (fun (x : sig.ret) (g' : VariableAssignment) => indicatorE (bad (L.get g'))) (fun (x1 x2 : ENNReal) => x1 ≤ x2) fun (x : sig.ParamType) (g : VariableAssignment) => step (cntr (L.get g))

      … and sets it with probability at most step cntr

    • incr (c : ℤ) : hoareProc (fun (x : sig.ParamType) (g : VariableAssignment) => inv (L.get g) ∧ ¬bad (L.get g) ∧ pre g ∧ cntr (L.get g) = c) p fun (x : sig.ret) (g' : VariableAssignment) => inv (L.get g') ∧ (bad (L.get g') ∨ c < cntr (L.get g'))

      … and increases the counter (unless it set bad)

    • same (c : ℤ) : hoareProc (fun (x : sig.ParamType) (g : VariableAssignment) => inv (L.get g) ∧ ¬bad (L.get g) ∧ ¬pre g ∧ cntr (L.get g) = c) p fun (x : sig.ret) (g' : VariableAssignment) => inv (L.get g') ∧ ¬bad (L.get g') ∧ c ≤ cntr (L.get g')

      the other calls do not set bad nor decrease the counter

    • keep : hoareProc (fun (x : sig.ParamType) (g : VariableAssignment) => inv (L.get g) ∧ bad (L.get g)) p fun (x : sig.ret) (g' : VariableAssignment) => inv (L.get g') ∧ bad (L.get g')
