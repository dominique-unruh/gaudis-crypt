    EasyCrypt's declare module #

    declare module A <: AdvPreimage «from» «to» {-RO, -Preimage}

    declares an abstract module A of a module type for the rest of the section, with EasyCrypt's restriction: A touches none of the globals of RO and Preimage. It is

    variable (A : AdvPreimage «from» «to») [Module.Declared A S]

    with S the join of those globals' footprints. Module.Declared A S bundles the two facts EC takes for granted about a declared module: finitely many globals, and none of them in S. As an instance-implicit section variable it is part of exactly the lemmas that mention A — EC's generalization over A when the section is closed — and fp_disjoint reads it like the restriction hypothesis FVP.fvP A ≤ Sᶜ it states.

    The restriction. Each -X names a module or a global variable:

    • a concrete module (a definition): its globals are the global_vars its code mentions, through the modules it uses (EC's glob X of a concrete module is read off its code the same way);
    • a global variable: itself;
    • a declared module (a section variable): glob X, EC's restriction against an abstract module.

    A region for glob A (exception E14 of the SHA-3 port).

    declare module D <: DISTINGUISHER {-C, -Perm} with glob R

    also declares a region R above D's footprint, restricted like D (Module.ECGlob D R, Footprint.Restricted R S), and {-R} in a restriction names it:

    variable (D_ll : ∀ (F <: DFUNCTIONALITY {-R}), ∀ (P <: DPRIMITIVE {-R}), … → islossless D(F, P).distinguish)

    This is for a lemma that restricts other modules against glob D (EC's {-D} on a module bound in a hypothesis) and is applied to a module built from a declared one, A(D'). EC's glob A(D') is glob D' and the variables of A, by definition; here the footprint of an application is bounded from above only, so {-A(D')} does not give {-D'}. Stated against R, the lemma is applied with the region written out, glob D' ⊔ C.c.footprint (an instance Module.ECGlob (A D') _, and Footprint.Restricted _ _ by ⟨by fp_finite, by fp_disjoint⟩). Applied to a declared module it is applied with R its glob (Module.ECGlob.declared, Footprint.Restricted.glob_declared).

    Representability (exception E2 of the SHA-3 port) is not a hypothesis: over a first-order module type it is a theorem (Module.representable_of_firstOrder), and Module.Declared.ecModule A ext gives Module.ECModule A ext with its side conditions discharged by default (ext the module type's canonical one, as Oracle.ext is).

        Concrete modules: their glob read off their code #

        EC checks a restriction against a concrete module from its code (glob Perm is Perm.m, Perm.mi). Here a concrete module carries Module.GlobBound A B: its footprint within a join B of global_vars (proven once, by fp_module, next to the module). Instance search then derives Module.Declared for it, and for a declared module against the glob of a concrete one, as EC does:

        • Footprint.Outside B S — B ≤ Sᶜ over the joins: global_vars by their Lens.Disjoint instances, the glob of a declared module (its restriction), of a concrete one (its bound);
        • Module.Declared.ofGlobBound — a concrete module is declared against what its bound stays outside;
        • Footprint.Covers S₀ S — what stays outside S₀ (finitely supported) stays outside S: the joinands of S₀, and the glob of a concrete module whose bound is within S₀ (Module.Declared.weakenCovers, weaken extended).

                                              def GaudisCrypt.tacticClear_decl_hyps :
                                              Lean.ParserDescr

                                              clear_decl_hyps: clear the hypotheses that state a declared module's restrictions (Module.Declared A S, Footprint.Restricted R S, Module.ECGlob A R: instances that declare module puts in the context), where nothing depends on them.
