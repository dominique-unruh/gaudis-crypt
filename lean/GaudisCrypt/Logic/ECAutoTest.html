    Golden tests of EC's auto (Logic/ECAuto.lean) #

    Each test pins what a tactic leaves: the goals, their order, tags and shape, as trace_state prints them (#guard_msgs). A change of a tactic that changes its output changes a test here; update the expected text (scripts/update_golden.py) only when the change is intended. The goals are then given up (sorry, its warning part of the expected text): the tests are about the tactic's output, not about closing it. The conditions use uninterpreted predicates (P, Q, R) so that the closers inside the tactic leave the goal.
