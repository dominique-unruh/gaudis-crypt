    Golden tests of bypr #

    The goal bypr leaves on a phoare judgment about a procedure (see Logic/ECAutoTest.lean for the format; scripts/update_golden.py refreshes the expected text).

    Type 1

    The module type declared by moduletype Coin, with fields flip: the type Module Coin.typeRep of modules that are a right-nested tuple of the field types.

    Build one from a record of its fields with Coin.mk, read a single field off one with the accessors Coin.flip, and get the whole record back with Coin.structure.

                noncomputable def GaudisCrypt.ByPrTest.Coin.flip :
                Coin → procmod (Bool) → Bool

                The field flip of a module of type Coin: the projection onto component 0 of the right-nested tuple Coin.typeRep, as a chain of Module.fst'/Module.snd'. Tagged @[module_accessor].

                Coin.flip.mk_simp reads this field back off a module built by Coin.mk; Coin.flip.utilities has the accessor as a module, and the lemmas about it.

                Its parameters are named b0, in that order (recorded in @[gaudiProcParamNames], a ProcedureSignature holding only their types).

                    The body of proc flip of module FairCoin, as a procedure of its own: it calls no module parameter, so it has no holes.

                    A hole stands for a call whose callee is not known here — a module parameter is supplied only when the module is applied — so the body is a ProcedureWithHoles, to be instantiated (see FairCoin.flip.procedure.apply_simp) rather than run. Use FairCoin.flip for this procedure as a module.
