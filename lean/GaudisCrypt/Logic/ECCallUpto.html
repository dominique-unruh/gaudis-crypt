    EasyCrypt's up-to-bad abstract call call (_: bad, I, J) — the rule #

    equiv_call (_ : §G1.bcol ∨ §G1.bext, ={C.c, C.queries} ∧ INV …, FMap.dom §C.queries{2} [])

    EC's call (_: bad, I, J) on D(O₁).f ~ D(O₂).f (D declared, O₁, O₂ concrete): before the bad event (on the right) the two runs agree on glob D, the results and I; after it, only J is kept. prhlProc_abstract_call_upto_ec is prhlProc_abstract_call_upto_module (Logic/AbstractCallUpto.lean) with EC's premises:

    • per oracle procedure o, EC's equiv[ O₁.o ~ O₂.o : !bad{2} /\ ={arg} /\ I ==> if bad{2} then J else ={res} /\ I ], ={glob D} framed syntactically (the oracles' writes keep glob D, StmtWithHoles.WritesKeep);
    • EC's right premise forall &1, phoare[ O₂.o : bad /\ J ==> bad /\ J ] = 1;
    • the left premise as a Hoare triple J is kept by O₁.o after bad;
    • D(O₁) and D(O₂) lossless.

    Deviation (exception E11 of the SHA-3 port, notes/SHA3/Exceptions.md): EC asks the left oracles lossless only after the bad event (forall &2, bad{2} => phoare[ O₁.o : J ==> J ] = 1), and D_ll with them; the rule here asks D(O₁), D(O₂) lossless outright (the tactic derives that from D_ll and each oracle's islossless), since its coupling after the bad event needs the adversary's remaining runs lossless. Every use in the SHA-3 proofs proves the oracles lossless outright.

    The tactic equiv_call (_ : bad, I[, J]) (bad unsided, about the right state; I, J relational): the global variables the three read become the view L (EC's invariants on memories, here on L's contents), and the goals come in EC's order —

    1. D_ll's statement (∀ (F <: … {-D}) (P <: … {-D}), islossless P.f → … → islossless D(F, P), the oracles' procedures in EC's order: the last component's first), closed by exact D_ll (for D declared with glob R, Logic/DeclareModule.lean, the statement is against R: ∀ (F <: … {-R}) …);
    2. per oracle procedure, in that order: the equivalence, the left oracle's islossless, the right one's phoare[ … : bad ∧ J ==> bad ∧ J ] = 1, and (the deviation) the right one's islossless;
    3. the code before the calls. The frame (={glob D} kept by the oracles), L's disjointness from D, the oracles' countable arguments and, when J does not read the left side, J's preservation on the left are closed.
