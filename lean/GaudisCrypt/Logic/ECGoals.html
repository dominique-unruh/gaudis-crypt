    EasyCrypt's goal selectors: on_goals #

    on_goals 1, 3 => auto        -- EC's `1,3: auto`
on_goals 2..-2 => tac        -- EC's `2..-2: tac` (a range; negative positions from the end)
on_goals -1 => tac           -- EC's `-1: tac`

    EC applies a tactic to the goals at the given positions (from 1; -k the k-th from the end) and leaves the others where they are; the goals each run leaves take its place. Batteries' on_goal n does it for one goal; EC's last first / first last are Lean's rotate_right / rotate_left.
