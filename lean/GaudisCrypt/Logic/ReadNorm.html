    The read normal form, and a strict skip #

    What a judgment tactic leaves for the logic is a goal about program states σ (one, or two for a relational judgment). The closers work on goals about plain values. The step between the two, generalizing every read of a state to a value, only works when the reads are spelled one way.

    The read normal form #

    A proposition P is in read normal form for the states σ₁ … σₙ when

    • (atoms) every occurrence of a state is inside a read x.get σ (a lens or getter x on the program state: a local variable) or X.get σ.globals (a global variable, a region's getter), where x, X mention no state;
    • (no expressions around reads) no eval, no (Getter.mk f).get σ, no read of a pair or a component lens: (x.pair y).get σ is (x.get σ, y.get σ);
    • (no reads through writes) no state other than the σᵢ themselves: x.get (y.set v σ) is x.get σ (or v), a reset or an inliner's renaming under a read is gone;
    • (tests) the Decidable instance of every decide/if is the one of the proposition as it stands, so that a read inside an instance is the same atom as the visible one;
    • (regions) a region that is a set of variables is read as the variables (TacticMisc.globTuples).

    ReadNorm.normalize brings a goal to this form with the existing steps, all of them, in one order: relSimpDecls (reads through writes), unfoldReads, normDecideGoal, normInst, globTuples. Until now each path applied its own subset (the Hoare and pHL paths no normDecide: the reads then do not generalize, and the goal silently stays about the states).

    ReadNorm.offenders lists the places where a state is used other than by an atom.

    ec_skip #

    EC's skip on a Hoare triple, a phoare judgment or a relational one whose code is used up: the implication, normalized, with every read generalized to a value. Unlike hoare_skip, phoare_skip and equiv_skip, it fails if a state survives, and says where it is still used. The generalized values are named after their variables (x, or x₁/x₂ by side).

    New name, old tactics unchanged: proofs move to it one file at a time (notes/SHA3/TacticReview.md, step 3).
