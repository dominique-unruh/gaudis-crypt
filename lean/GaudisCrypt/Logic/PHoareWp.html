    Backwards reasoning for probabilistic Hoare judgments #

    The tactics of Logic/HoareWp.lean and Logic/Inline.lean, for phoareStmt:

    • phoare_inline n — inline call site n (the inliner of hoare_inline);
    • phoare_split k — regroup the statement, the last k statements in a block of their own;
    • phoare_wp k — replace the expectation by the exact expectation of the last k statements (phoareStmt_seq_iff). Exact for every statement but a loop: an abstract call stays a symbolic Procedure.ewp term, a conditional with calls in its branches becomes an if of the branches' expectations (phoareStmt_seq_if);
    • phoare_skip — at skip, the inequality or equation itself, reads generalized.

    Conditionals with samplings or calls in Hoare triples #

    A Hoare triple is a pHL judgment with bound 0 (hoareStmt_iff_phoareStmt), so a conditional whose branches sample or call gets its wp from the expectation calculus: each branch's outcomes off the postcondition have probability 0, an expectation postSimp computes with the Stmt.ewp lemmas and turns back into a condition on the support (expected_eq_zero_iff).

    source
    theorem GaudisCrypt.SubProbability.expected_eq_zero_iff {α : Type u_1} (μ : SubProbability α) (f : α → ENNReal) :
    μ.expected f = 0 ↔ ∀ a ∈ μ.support, f a = 0

    An expectation is 0 iff the function vanishes on the support (the measure is discrete).
