    EasyCrypt's if on the first statement #

    stmt_if          -- EC's `if`: the first statements, conditionals (on both sides of `equiv`)
stmt_if{i}       -- EC's `if{i}`: side `i`'s first statement, a conditional
stmt_rcondt{i} n -- EC's `rcondt{i} n`: statement `n` a conditional whose test holds there
stmt_rcondf{i} n -- EC's `rcondf{i} n`: … whose test fails there

    EC's if works on the first statement of the code, the rest following each branch. Here the conditional takes the rest into its branches (StmtWithHoles.Equiv.ifThenElse_seq, an equivalence, for any judgment), then the judgment's rule for a conditional applies: hoareStmt_if, phoareStmt_if (any relation to the bound), prhlStmt_if (the guard goal: the tests agree), or prhlStmt_if_left/_right. Goals in EC's order: guard for the two-sided rule (the tests agree), then then, else (the precondition with the test true, false).

    rcondt, rcondf: a conditional whose test is known #

    EC's rcondt n (rcondf n): the statement at position n is a conditional whose test holds (fails) wherever the code before it ends, from the precondition (a Hoare triple on that code); the conditional is replaced by its branch. On a loop (EC's rcondt/rcondf on a while), the loop unrolled first (Stmt.Equiv.unroll): rcondt leaves its body before the loop, rcondf nothing.
