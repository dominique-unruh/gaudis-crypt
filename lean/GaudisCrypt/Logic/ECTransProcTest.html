    Golden tests of transitivity on procedures (Logic/ECTransProc.lean) #

    EC's transitivity N.f (P₁ ==> Q₁) (P₂ ==> Q₂) (see Logic/ECAutoTest.lean for the format; scripts/update_golden.py refreshes the expected text).

    source
    noncomputable def GaudisCrypt.ECTransProcTest.A.f.procedure :
    proctype () -> Bool

    The body of proc f of module A, as a procedure of its own: it calls no module parameter, so it has no holes.

    A hole stands for a call whose callee is not known here — a module parameter is supplied only when the module is applied — so the body is a ProcedureWithHoles, to be instantiated (see A.f.procedure.apply_simp) rather than run. Use A.f for this procedure as a module.

      theorem GaudisCrypt.ECTransProcTest.A.f.procedure.apply_simp (holeArgs✝ : HoleSigs.empty.Instantiation) :
      procedure.instantiate holeArgs✝ = proc () : Bool { var b : Bool; b <$ EC.dbool; return §b }

      Instantiating the holes of A.f.procedure with a tuple holeArgs of procedures: the body of proc f as written, with each hole call replaced by the matching holeArgs.lookup (HoleIndex.zero being the first hole the body declared). True by rfl.

      Deliberately not @[simp], unlike the other apply_simp lemmas: its right-hand side is the whole body written out, so letting it fire on its own would turn any goal mentioning an instantiated procedure into that body. Inlining a procedure is a step to ask for by name (simp [A.f.procedure.apply_simp]).
