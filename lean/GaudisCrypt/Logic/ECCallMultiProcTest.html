    Golden tests: a declared module with several procedures and an oracle #

    EC's module type Adv (O : POr) = { proc a1 … proc a2 … }, declare module A <: Adv {-…}: the call rules on A(O).a1, A(O).a2 (an accessor of the functor's result): the invariant call with EC's frame of the untouched globals, the up-to-bad call with EC's full precondition, swap of a sampling into a global past the call, and pHL's call with the adversary's losslessness; and inline of the oracle of a cloned theory (clone import ROM as H, H.Lazy.LRO.o) (see Logic/ECAutoTest.lean for the format; scripts/update_golden.py refreshes the expected text).
