    EasyCrypt's call (: P ==> Q) in a phoare, with a frame #

    phoare_call (: P ==> Q) / x₁, …, glob A
hoare_call (: P ==> Q) / x₁, …, glob A

    EC's call (: P ==> Q) keeps, past the call, what the callee does not touch (EC's glob): the game's event after the call need only follow from Q for globals that agree with the ones before on that. Here that is a frame (Module.Proc.Frame, Logic/ECCallOneSided.lean): lenses outside the callee (Preimage2.hash past FEL(A, F).main), the glob of declared modules. Upper bounds (phoareStmt_call_le_frame).

    In a Hoare triple (hoare_call_wp_frame) the same frame serves EC's rcondt{i} n; first by auto; inline*; auto; conseq (: _ ==> true); auto: the condition after a call that does not write what it reads is hoare_call (: True ==> True) / x; ec_auto.

    hoare[ P (args.get CurrentState.state) CurrentState.state.globals ∧ ∀ (r : sig.ret) (g : VariableAssignment), Fr CurrentState.state.globals g → Q r g → B (x.set r (ProgramState.globalL.set g CurrentState.state)) ==> B CurrentState.state ] { x <- call M.procedure (§args); }

    EC's call (: P ==> Q) in a Hoare triple, with EC's frame: the postcondition after the call for every result and every globals that Q allows and that are in the frame Fr of the current ones (what the callee does not write keeps its value).
