    Lower bounds of footprints: a module's writes #

    fp_le bounds FVP.fvP M from above. EC's ={glob M} of a concrete module M is the equality of M's variables; ours is the equality on FVP.fvP M's touched getter (glob M is the region M may touch), and to get a variable's equality back, the variable must lie inside that region: a lower bound.

    A region containing every constant write of a lens x (Footprint.HasWrites) contains x's tests (Footprint.HasWrites.testKer_mem, the argument of Lens.testKer_mem_footprint), and the tests read x: equal on the region, so equal on x (Lens.get_eq_of_touched_getter_eq_of_hasWrites). A procedure whose code assigns the global x somewhere (its callees included) has all of x's constant writes in its footprint: an assignment's footprint is that of the writes of every value (FVP.fvpInductiveFunctionGS.setter).

    fp_writes   -- `(FVP.fvP M).HasWrites x`, `M` a concrete module assigning `x` somewhere

    fp_writes goes down M's module type to its procedures (Module.fst'/Module.snd', each a lower bound of M's footprint), unfolds each as the inliner does (Flatten.unfoldProcedure) and looks for an assignment of x in its code (callees' bodies included). EC reads a concrete module's globals off its code; this is that reading, for the variables the module writes.
