    Tactics for relational judgments (pRHL) #

    prhlStmt registers one descriptor per side with the judgment registry (Logic/Judgment.lean), so the generic statement steps work on it, on both sides or on one ({1}, {2}):

    • stmt_inline n, stmt_inline{i} n — inline call site n (EC's inline);
    • stmt_split k, stmt_split{i} k — regroup the last k statements;
    • stmt_wp, stmt_wp k, stmt_wp{i} k — wp over deterministic code (EC's wp); over a sampling on one side, rnd{i} (the distribution must be lossless).

    And the relational steps proper:

    • equiv_proc_to_stmt — from equiv[ M₁ ~ M₂ : P ==> Q ] to the judgment about the two call statements (inlined by stmt_inline 0; EC's proc, to the bodies, is equiv_proc, Logic/ECProc.lean);
    • equiv_rnd, equiv_rnd f — the two last statements are samplings, coupled along f (default: the identity) (EC's rnd);
    • equiv_rnd_run k — a sampling on the left against the last k statements on the right, which sample the same;
    • equiv_while_raw I — synchronized loops with the invariant I (four goals; EC's while I is equiv_while, Logic/ECWhileRel.lean);
    • equiv_call h — the last statements are calls, related by the procedure judgment h (EC's call; prhlProc_glob hA for an abstract procedure, EC's call (_ : ={glob A})); equiv_call alone for calls of the same procedure from equal arguments and globals;
    • equiv_seq_last k₁ k₂ : M — cut after all but the last k₁ / k₂ statements (EC's seq counts from the start: equiv_seq, Logic/ECSeq.lean);
    • equiv_case P — case analysis on a relation of the initial states (EC's case);
    • equiv_if, equiv_if{i} — conditionals on both sides, or on one (EC's if, if{i});
    • equiv_sym — swap the sides;
    • equiv_rcondf{i} — a trailing loop on side i whose guard is false (EC's rcondf{i});
    • equiv_skip — at skip ~ skip, the implication, with the reads of both states generalized (x₁, x₂; EC's skip).

    Relations written in tactics (I, M, P, the coupling f) are relational conditions as in equiv[ … ]: §x{1}, §x{2}, ={x}, over the program variables of the goal.

          def GaudisCrypt.PRHLWp.generalizeReadsRel (g : Lean.MVarId) (normDec : Bool := false) :
          Lean.MetaM Lean.MVarId

          On a goal ∀ σ₁ σ₂ : ProgramState, P σ₁ σ₂: generalizeReads for both states — every read of σ₁ becomes a value x₁, every read of σ₂ a value x₂ (named after the variable), and the states are dropped if nothing else mentions them; a state that occurs other than read is left alone (onlyRead), its reads with it. Where the globals themselves occur (§allGlobals, the globals a call leaves), they become a value globals₁/globals₂ first, and the reads of global variables stay reads of it (x.get globals₁), so nothing is lost. Atomic, as generalizeReads.

                                                                def GaudisCrypt.PRHLWp.tacticEquiv_sim :
                                                                Lean.ParserDescr

                                                                equiv_sim: EC's sim on straight-line code. Backwards over both statements, as long as one of these applies: stmt_wp (trailing deterministic code, both sides), equiv_call (calls of the same procedure, or of procedures spelled differently, their equality tried by rfl and left as a callee goal otherwise). It stops at anything else (a conditional, a loop, a sampling, calls of different procedures), leaving that goal: cut there with equiv_seq … : M.
