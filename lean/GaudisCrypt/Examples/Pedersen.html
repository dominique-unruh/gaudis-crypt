    The Pedersen commitment scheme (EasyCrypt examples/Pedersen.ec) #

    Pedersen, "Non-interactive and information-theoretic secure verifiable secret sharing". EC's file, declaration by declaration and script line by line: correctness, perfect hiding (the unhider wins with probability exactly 1/2), and computational binding by reduction to the discrete logarithm (Lib/EC/DLog.lean). All of EC's lemmas are proven.

    Translation:

    • clone DLog as DL. import DL.G DL.GP DL.FD DL.GP.ZModE. clones the theory without instantiating it: the file stays abstract in the group, the section's variable {group exp} … [CyclicGroup.Params group exp] (Lib/EC/Group.lean); EC's DL.DLog.X is DLog.DLog.X, DL.StdRedAdversary is DLog.StdRedAdversary.
    • theory PedersenTypes (value = group, message = exp, commitment = group, openingkey = exp) is written out in the clone of Commitment.
    • The lemmas' (U <: Unhider), (B <: Binder) are the binders ∀ (U <: Unhider).
    • EC's local module FakeCommit(U : Unhider) is a module with a module parameter, as there.

    Gap list (what keeps the file from reading as EC's; items of the examples' infrastructure batch):

    • GAP 1 (closed 2026-11-15): EC's call (_ : true) on the adversary is equiv_call (_ : True).
    • GAP 2 (closed 2026-11-15): pHL on an event reached with probability 1 — call H with H : islossless f, rnd, auto — keeps the judgment an event, as EC does (Logic/PHoareRnd.lean): fakecommit_half is EC's script.
    • GAP 3 (closed 2026-11-15): after inlining, x is a group element on the left (Correctness's key) and an exponent on the right (FakeCommit's secret): two variables of one name. §x{2} is the right side's, in the tactics' conditions and in the goals as shown.
    • GAP 4: islossless closes the samplings (EC's hint random) and leaves the calls; EC's takes the hypotheses uc_ll, ug_ll and leaves the samplings. hi_ll ends with assumption where EC's ends with apply dt_ll || apply DBool.dbool_ll.
    • GAP 5 (closed 2026-11-15): byequiv on Pr[…] ≤ Pr[…] closes the events' implication res{1} → res{2} itself, as EC's => //.
    • GAP 6: the field algebra of pedersen_computational_binding (EC's field, ring, pow_bij) is by hand, as is naming what auto => /> x _ [c m d m' d'] /= comm comm' m_neq_m' names (rename_i, obtain).
    • GAP 8 (closed 2026-11-15): inline{2} DL.StdRedAdversary(DLogAttacker(B)).guess finds the call the experiment makes through its module type.
