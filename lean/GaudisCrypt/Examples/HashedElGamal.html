    (EasyCrypt examples/hashed_elgamal_std.ec)

    EC's file, declaration by declaration and script line by line; all five lemmas are proven.

    Translation (as Examples/ElGamal.lean):

    • op k : { int | 0 < k } as gt0_k is the class Params; clone import BitWord as Bits with op n <- k … rename "word" as "bits" "dunifin" as "dbits" is the abbreviations bits, dbits of Lib/EC/BitWord.lean at k.

    • module type AdvES = { proc guess(_: hkey * bits) : bool } takes one pair, which EC identifies with two parameters (ESAdv(A).guess (hk, h) declares two, A.guess(hk,h) passes two): two parameters here.
    • EC's type abbreviations pkey, skey, ptxt, ctxt are written out in the clone of PKE_CPA; declare axioms are section hypotheses; Gb takes the section's A as its parameter.

    Gap list (the examples' infrastructure batch; numbers as in Examples/ElGamal.lean where the gap is the same):

    • GAP 1: inline writes a call's parameters as one tuple assignment, EC as one per parameter: stmt_split_params after stmt_inline*.
    • GAP 2: swap{1} 1 1 moves the first statement of an inlined body later: inline leaves a reset_vars of the callee's locals before it, which EC's count attaches to that statement, and the reset does not commute with the next statement (it resets its variable). Written with our position, stmt_swap_raw{1} 2 1, which moves the sampling alone. (Moving earlier past a reset works.)
    • GAP 3: in Gb_half EC calls Ag_ll and Ac_ll by hand (call Ag_ll; auto. call Ac_ll; auto=> />; rewrite dhkey_ll dt_ll dbits_ll); phoare_call followed by phoare_auto computes through the code before the call and leaves an expectation, so the lossless part is one islossless.
    • EC's rnd f (an involution) is equiv_rnd f f.
