    The padded block sponge construction (EasyCrypt proof/BlockSponge.ec) #

    The sponge on blocks: absorb a valid block list, squeeze n blocks. Its ideal functionality is the infinite random oracle BIRO.IRO on valid block lists, and its simulator is the squeezeless sponge's (Gconcl.S) through Last.

    Translation notes (see notes/SHA3/README.md):

    • clone include Indifferentiability with type p <- block * capacity, type f_in <- block list * int, type f_out <- block list rename … "Indif" as "Experiment" … is the abbreviations below.
    • op parse with its axioms formatK, parseK, parse_nil is the parameter class Params (over SLCommon.Params).
    • A procedure whose EasyCrypt parameters (bl, nb) are the module type's single parameter (f_in = block list * int) takes that pair, x, and names its components.
    • module Sim (F) = Gconcl.S(Last(F)) is the composite functor Module.comp Gconcl.S Last.
    • Last : SLCommon.DFUNCTIONALITY has, in EasyCrypt, also an empty init outside its type: here Last has the type's f alone, and Last.init is a module of its own.
    • DRestr(D)(F)(P) takes D as a Lean parameter, as in SLCommon.

    Indifferentiability: `clone include Indifferentiability with type p <- block * capacity, #

    type f_in <- block list * int, type f_out <- block list rename [module] "Indif" as "Experiment" [module] "GReal" as "RealIndif" [module] "GIdeal" as "IdealIndif"`
