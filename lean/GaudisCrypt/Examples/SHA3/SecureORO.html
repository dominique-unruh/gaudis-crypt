    Random oracles with failing queries are preimage, second-preimage and collision resistant — #

    the EC-fidelity port (EasyCrypt proof/SecureORO.eca)

    SecureRO (SecureRO.lean) for oracles returning options: Bounder answers None once its bound queries are used up. Translated as the pilot SecureRO:

    • the theory's operators and axioms are the class Params from to (outParam types: a clone is an instance), the module types and modules written as EC's (RF, Bounder(F), A(Bounder(F)));
    • clone import PROM.FullRO as RO is the clone's RO.m, FRO.m, RO, RO.LRO, FRO, RO_LRO_D (as the pilot SecureRO's);
    • the procedure aliases of RF(R) (proc init = R.init, proc sample = R.sample) and of Bounder (proc sample = F.sample) are wrapped in a call (exception E5).

    Declarations of the first port #

    Definitions and plain lemmas of the first port of this file (2026-10/11) that the proofs below use; its program-logic proofs are gone.

    The first port's translation notes (some mention declarations that went with its proofs):

    • EasyCrypt's module type RF and module RF share a name; the module type is RF_T (exception E3).
    • RF(R) (proc init = R.init, proc sample = R.sample) and Bounder(F) (proc sample = F.sample) are used as functors, so their aliased procedures call the aliased ones (exception E5).
    • The module variables (Bounder.bounder, the clone's RO.m, FRO.m, and the sections' local Preimage2.hash, SecondPreimage2.m2, D1.m1) are lens parameters (exception E6 for the local ones).
    • The proofs are SecureRO's, step for step; the potentials of EC's fel and the lemmas on them are SecureRO's (their counter component 0: there is no Counter here).
