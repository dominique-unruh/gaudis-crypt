    Indifferentiability with failing oracles (EasyCrypt proof/OptionIndifferentiability.eca) — #

    EC-fidelity port

    Indifferentiability.eca with procedures that may fail: the primitive and the functionality return options, and every name gets an O prefix. The translation is that of Indifferentiability.lean: the theory's types are outParams of the (field-less) class Params p f_in f_out, so a clone is clone OptionIndifferentiability as OIndif with type p <- … (Syntax/Clone.lean); EC's subtyping of module types is module_subtype; EC's call restrictions ({ P.f }) are not part of a module type (exception E2 of the port), they are the ext of declare module's representability.
