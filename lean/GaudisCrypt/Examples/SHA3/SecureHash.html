    Security games for hash functions with failing oracles (EasyCrypt proof/SecureHash.eca) — #

    EC-fidelity port

    Preimage, second-preimage and collision games for a construction F : OCONSTRUCTION over a primitive P : OPRIMITIVE, against an adversary whose oracle calls are bounded by bound (FBounder, PBounder). The file has no lemmas: SHA3OSecurity clones it.

    Translation (as the pilot SecureRO's):

    • the theory's operators and axioms are the class Params from to block, whose types are outParams (a clone is an instance), so they are written without types, as in EC;
    • clone import OptionIndifferentiability as OIndif with … is clone (Syntax/Clone.lean);
    • Bounder.bounder is a global_var; EC's paths A(FBounder(F(P)), PBounder(P)) are terms, the subtyping OPRIMITIVE <: ODPRIMITIVE a coercion on the arguments;
    • the games' results m1 <> m2 /\ exists y, … are decided classically, as EC's logic is;
    • EC's commented-out PROM.GenEager clone and module type RF are left out.
