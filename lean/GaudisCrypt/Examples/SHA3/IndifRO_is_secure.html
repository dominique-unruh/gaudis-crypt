    A construction indifferentiable from a random oracle is secure — the EC-fidelity port #

    (EasyCrypt proof/IndifRO_is_secure.ec)

    Collision, preimage and second-preimage resistance of FM(C, P) (a construction C over a primitive P), from the resistance of the random oracle (SecureRO) and the indifferentiability of C(P) from it, up to bound.

    Translation (as the pilot SecureRO's):

    • the file's types and operators, and their axioms, are the class Params block f_in f_out (SHA3Security's clone is an instance of it);
    • clone import SecureRO as SRO with … and clone import Indifferentiability as Indiff0 with … are clone (Syntax/Clone.lean): the instances SRO.params, Indiff0.params, and the aliases SRO.Bounder, SRO.RO_is_collision_resistant, Indiff0.GReal, … opened;
    • EC's SRO.RO.RO is the pilot's RO (the pilot's clone of PROM.FullRO is flattened into RO, RO.LRO, FRO, RO.m), so here SRO.RO;
    • the procedure aliases of FInit, GetF, SInit, FM, DColl are EC's (proc f = c;, since 2026-11-20; RO's are its procedures themselves); FInit and FM are declared at SRO's module type RO_T (EC's RO), their procedure f, which nothing calls, left out (EC types them structurally), FM's rem before sample as the module type has them;
    • EC's C(P) is «C»(P): C( is Mathlib's notation for continuous maps.
