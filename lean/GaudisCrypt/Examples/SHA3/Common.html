    SHA-3: common definitions and lemmas (EasyCrypt proof/Common.ec) #

    The sponge's rate r and capacity c; blocks and capacities as bit words; the ideal permutation Perm; padding, chunking and the conversions between bits and blocks; the validity predicates.

    The mapping conventions are in notes/SHA3/README.md, the declaration-by-declaration status in notes/SHA3/Mapping.md. In this file:

    • op r : { int | 2 <= r } as ge2_r and op c : { int | 0 < c } as gt0_c (abstract constants with axioms) are the fields of the parameter class Params. Every later file takes [Common.Params].
    • clone export BitWord as Block with op n <- r rename "word" as "block" … is the namespace Block of abbreviations at n := r, exported; Capacity likewise.
    • clone export PRP as PRPt with type D <- block * capacity, clone export StrongPRP as PRPSec and clone export RP as Perm with op dD <- bdistr \*` cdistrare applications of `GaudisCrypt/Lib/EC/PRP.leanatD := block × capacity`.
    • int is ℤ, %/, %%, %| are /, %, ∣ (EasyCrypt's division is Euclidean, as Lean's on ℤ), and list operations on int are those of GaudisCrypt/Lib/EC/List.lean.
