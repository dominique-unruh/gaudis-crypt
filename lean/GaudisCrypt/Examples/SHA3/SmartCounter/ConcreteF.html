    From the permutation to a random function (EasyCrypt proof/smart_counter/ConcreteF.eca) — #

    EC-fidelity port

    The real game with the ideal permutation is close to the same game with PF, a random function with an inverse, up to the PRP/PRF switching bound (Real_Concrete).

    Translation (as SmartCounter/SLCommon.lean):

    • local clone import Strong_RP_RF as Switching with type D <- state, op uD <- dstate, … is the namespace Switching: the clone's module variables (PRPi.m, ARP.coll, DBounder.FBounder.c, …) global_vars, its modules the library's (Lib/EC/Strong_RP_RF.lean) at them, its realized axioms lemmas. (EC's local has no counterpart: the clone's names stay visible.)
    • declare module D <: DISTINGUISHER {-Perm, -C, -PF, -Redo} and declare axiom D_ll as in EC; the local modules GReal', D' are definitions (D' with D a Lean parameter, as DRestr).

    Declarations of the first port #

    Definitions and plain lemmas of the first port of this file (2026-10/11) that the proofs below use; its program-logic proofs are gone.

    The first port's translation notes (some mention declarations that went with its proofs):

    • The section's declare module D <: DISTINGUISHER {-Perm, -C, -PF, -Redo} and declare axiom D_ll are hypotheses of the lemmas. So are the local modules' parameters.
    • local clone import Strong_RP_RF as Switching with type D <- state, op uD <- dstate, type K <- unit, op dK <- dunit tt, op q <- max_size is the namespace Switching, and its realized axioms ge0_q, uD_uf_fu are lemmas. The clone is local, so its module variables are lens parameters of the local declarations that mention them (exception E6).
    • EasyCrypt checks this file only up to an anomaly at line 418 (inside the proof of Real_Concrete); see notes/SHA3/README.md.
