    The squeezeless sponge: common definitions (EasyCrypt proof/smart_counter/SLCommon.ec) — #

    EC-fidelity port

    The construction SqueezelessSponge, the counting and restricting wrappers C, PC, DPRestr, FC, DFRestr, DRestr, and their lemmas. The operators without modules (the parameter class with max_size, state, the Prefix theory, the handle operators) are SmartCounter/SLCommonCore.lean, shared with the first port.

    Translation (as the pilots' IndifRO_is_secure):

    • clone include Indifferentiability with type p <- state, … rename [module] "GReal" as "RealIndif" [module] "GIdeal" as "IdealIndif" is clone import … as Indiff (clone has no include and no rename), RealIndif and IdealIndif aliases of GReal, GIdeal;
    • clone import FullRO as F with … is the namespace F of PROM.FullRO at the clone's types, its module variables global_vars;
    • the procedure aliases of PRestr, FRestr (proc f = DPRestr(P).f) are wrapped in a call (exception E5);
    • DRestr(D, F, P) takes D as a Lean parameter: DRestr(D) is EC's partial application.

    Declarations of the first port #

    Definitions and plain lemmas of the first port of this file (2026-10/11) that the proofs below use; its program-logic proofs are gone.

    The first port's translation notes (some mention declarations that went with its proofs):

    • op max_size : { int | 0 <= max_size } as max_ge0 extends the parameter class: Params.
    • prefix is a Lean keyword, hence «prefix».
    • clone include Indifferentiability with type p <- state … is the abbreviations below (PRIMITIVE …, Indif, RealIndif, IdealIndif); clone import FullRO as F … is the namespace F.
    • Modules whose procedures alias another module's (PRestr, FRestr: proc f = DPRestr(P).f) are Lean functions assembling the procedures with T.mk.
    • DRestr(D : DISTINGUISHER, F, P) takes D as a Lean parameter, so that DRestr D is a DISTINGUISHER (EasyCrypt uses it partially applied, DRestr(D)).
    • A memory restriction {-C} is a footprint hypothesis against C.footprint.
