    Conclusion of the squeezeless sponge proof (EasyCrypt proof/smart_counter/Gconcl.ec) — #

    EC-fidelity port

    The equivalences G2_G3, G3_G4, G4_Ideal in EC's scripts, over the old port's declarations of IF, S, G3, G4 (section FirstPort below), as SmartCounter/Gext.lean.

    Translation:

    • EC's local G3(RO), G4(RO) take D as a Lean parameter (the section's D): G3(D, F.LRO) for EC's G3(F.LRO);
    • declare module D <: DISTINGUISHER {-C, -Perm, -F.RO, -F.FRO, -S, -Redo} with the section's local clone import Gext as Gext0: the clone's modules are fresh for D in EC, here D's restriction names them (G1, FRO.m).

    Declarations of the first port #

    Definitions and plain lemmas of the first port of this file (2026-10/11) that the proofs below use; its program-logic proofs are gone.

    The first port's translation notes (some mention declarations that went with its proofs):

    • module IF = { proc init = F.RO.init proc f = F.RO.get } is a definition assembling the aliased procedures.
    • The section's local clone import Gext as Gext0 is Gext, opened. The clone's module variables (G1.m, PF.m, ROhandle.FRO.m …) are fixed global_vars here, so their freshness for D is the hypothesis Gext0Fresh D (exception E13).
    • G3(RO : F.RO) and G4(RO : F.RO) take the module type F.RO (F.RO_T, exception E3). Their inner modules depend on RO only: they are functors of RO (G3.M, G3.S, G4.C, G4.S); G3 D, G4 D are the games' distinguish, with D a Lean parameter, and take EasyCrypt's d_in_t = unit argument, so that they are F.RO_Distinguishers (for RO_LRO_D).
