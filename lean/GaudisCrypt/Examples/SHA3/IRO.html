    The infinite random oracle (EasyCrypt proof/IRO.eca) — EC-fidelity port #

    It maps values of type from to infinite sequences of values of type to, each sampled uniformly and independently; it is lazy. Inputs not satisfying the validity predicate are mapped to the empty list.

    Translation (as the pilot SecureRO's):

    • the theory's operators are the class Params to from, whose types are outParams (a clone is an instance), so valid, dto are written without types, as in EC;
    • the module variables IRO.mp, IRO'.mp, IRO'.visible are module_vars;
    • EC's module type IRO and module IRO share a name: the module type is IRO_T (exception E3);
    • f's parameters (x, n) are one pair, the type a functionality's f has where IRO is one (BlockSponge's f_in <- block list * int), which EC identifies with two parameters;
    • module IRO : IRO's annotation is left out: IRO has more procedures (fill_in) than IRO_T.
