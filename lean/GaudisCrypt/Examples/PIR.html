    Private information retrieval (EasyCrypt examples/PIR.ec) #

    Two-server PIR: to read entry i of a database a replicated on two servers without either server learning i, the client sends the first server a random subset s of the indices [0, N) and the second server s with i flipped; each server returns the xor of the entries it was asked for, and the two answers xor to a i.

    EC's file, declaration by declaration and script line by line: correctness (PIR_correct), security by a coupling (PIR_secure1, PIR_secure2 and the two byequiv lemmas), the probability of each query computed in pHL (Pr_PIR_s, Pr_PIR_s' and the two bypr lemmas), and the uniformity equivalences (PIR_s_uniform, PIR_s'_uniform). All of EC's lemmas are proven.

    Translation:

    • clone import BitWord as BS, op N, op a, axiom N_pos are the class Params (n the length of BS.word); clone import Bigop as BBS is a clone of Lib/EC/Bigop.lean.
    • var s, s' : int list of module PIR are global_var PIR.s, PIR.s' before the module.
    • var j <- 0 is the declaration and the assignment j <- 0.
    • pHL's bounds are reals, as EC's: 1 / 2 ^ (N - §j) is 1%r/2%r^(N-j) (an integer power).
    • int fset is FSet ℤ (Finset), `|` and `&` are ∪ and ∩, oflist and the membership lemmas are Lib/EC/FSetOflist.lean; b ^^ (j \in x1) is b ^^ decide (j ∈ x1).

    Gap list (what keeps the file from reading as EC's):

    • GAP 1 (closed 2026-11-16): PIR_correct's conseq (_: _ ==> sxor2 PIR.s PIR.s' i) and its while are EC's: hoare_conseq and hoare_while keep what the precondition says of the variables the code does not modify (i = i0), as EC's do.
    • GAP 2: PIR_correct's loop body is one smt_close [sxor2_cons, sxor_cons] where EC takes the cases apart first (case: (j{m} <= i{m}), …); EC's ring on the two answers is the lemma xorw_cancel.
    • GAP 3: while (={j,PIR.s});auto is equiv_while (={j, PIR.s}) <;> equiv_auto, then auto_progress; EC's rnd (fun x => !x) is equiv_rnd (fun x => !x) (fun x => !x).
    • The variant of pHL's while (true) (N-j) is a natural number: (N - §j).toNat.
    • GAP 4: the restr lemmas are proven from mem_restr (membership in restr s n) where EC rewrites with FSet lemmas and calls smt. In PIR_s_uniform, PIR_s'_uniform the conditions of rnd are split by hand as in EC (EC's two ring are a case analysis on the booleans), and EC's rewrite !oflist_cons !restrS // goes into the hints of smt_close.
    • GAP 5 (closed 2026-11-16): (s, s') <- ([], []) is EC's tuple assignment (the condition sp leaves on the pair is taken apart by the closer).
    • GAP 6 (Pr_PIR_s, Pr_PIR_s'): byphoare (: True ==> _) for EC's byphoare=> // (the default precondition fixes the argument and the memory); case: (is_restr x N) is by_cases; the rule for while I V k ε has two goals more than EC's (bound_le_one, sat: Logic/PHoareWhileRev.lean); exists * j, PIR.s; elim * => j0 s0 is two stmt_exists *; EC's smt (…) on the restr lemmas are smt_close […] with EC's hints, the rewrites that precede them (rewrite oflist_cons, rewrite -set0E) added to the hints; one hint list differs (the ¬ E bound of the second seq: EC's membership lemmas in_fsetU in_fset1 nin_is_restr are is_restr_diff is_restr_Ueq is_restr_restr), and ENNReal.ofReal_zero is a hint where the bound is 0. By hand: the two goals of the loop rule that EC does not have, pre_bound (EC: have ->>: j = N by smt()), the variant goal (EC: smt (dbool_ll)), and the final equation on powers of two (EC: rewrite -exprS, ring).
