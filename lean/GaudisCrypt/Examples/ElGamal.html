    ElGamal is IND-CPA under DDH (EasyCrypt examples/elgamal.ec) #

    EC's file, declaration by declaration and script line by line (the pilot of the examples' re-port, 2026-11-15). All four lemmas are proven.

    Translation:

    • clone DiffieHellman as DH. import DH.DDH DH.G DH.GP DH.FD DH.GP.ZModE. clones the theory without instantiating it: the file stays abstract in the group, which is the section's variable {group exp} … [CyclicGroup.Params group exp] (Lib/EC/Group.lean), and the theory DDH is opened. clone DH.GP.ZModE.ZModpField as ZPF is Mathlib's Field exp.
    • EC's type abbreviations pkey = group, skey = exp, ptxt = group, ctxt = group * group are written out in the clone of PKE_CPA.
    • declare axiom Ac_ll, Ag_ll are section hypotheses, included where EC's proofs use them.
    • EC's local module Gb reads the section's A; here A is its parameter (Gb(A).main), and it is declared before the section.

    Gap list (what keeps the file from reading as EC's; each is an item of the examples' infrastructure batch):

    • GAP 1: inline writes a call's parameters as one tuple assignment, EC as one assignment per parameter, so EC's positions are off by the number of parameters less one, and a swap between two parameters has nothing to move past: stmt_split_params after stmt_inline* (Logic/ECInlineParams.lean), until the inliner does it.
    • GAP 2 (closed 2026-11-15): EC's call (_ : true) on the adversary is equiv_call (_ : True).
    • GAP 3 (closed 2026-11-15): Gb_half is EC's script; pHL rnd E and conseq on an exact bound and the tactic islossless are Logic/PHoareRnd.lean.
    • GAP 4 (closed 2026-11-15): module ElGamal : Scheme with its third procedure dec, which Scheme does not list, as in EC (ElGamal.dec is a procedure of its own).
    • GAP 5 (closed 2026-11-15): EC's rnd f g is equiv_rnd f g (Logic/ECRnd.lean).
    • GAP 6 (goals as shown): byequiv states ={allGlobals} (the whole global state) where EC shows ={glob A}.
