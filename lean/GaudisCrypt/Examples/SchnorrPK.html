    The Schnorr proof of knowledge is a Sigma protocol (EasyCrypt examples/SchnorrPK.ec) #

    EC's file, declaration by declaration and script line by line: completeness (with its losslessness), special soundness and special honest-verifier zero knowledge, all proven.

    Translation (as Examples/ElGamal.lean):

    • clone Group.CyclicGroup as G … clone GP.FDistr as FD. clone GP.ZModE.ZModpField as ZPF. is the section's group (Lib/EC/Group.lean), the field's lemmas Mathlib's.
    • theory SchnorrTypes: its type abbreviations (statement = group, witness = exp, …) are written out in the clone of SigmaProtocol; R_DL is a proposition.
    • clone import SigmaProtocol as SP with … op R = R_DL, op de = dt is clone import; the theory's R is opened (EC's export SigmaProtocol).
    • The proofs' (D <: SigmaTraceDistinguisher) is the binder ∀ (D <: SigmaTraceDistinguisher).

    Gap list (the examples' infrastructure batch; numbers as in Examples/ElGamal.lean where the gap is the same):

    • GAP 1: stmt_split_params after inline* (one assignment per parameter, as EC).
    • GAP 3 (closed 2026-11-15): the path SimulateHonestVerifier(SchnorrPK, SchnorrPKAlgorithms, D).gameIdeal into a module without a module type that has several module parameters.
    • GAP 5 (closed 2026-11-15): byphoare (_: h = x /\ w' = w ==> _) on a clone's game is byphoare (: §x = h ∧ §w = w' ==> _).
    • GAP 6: EC's seq 2 2 : (#pre /\ ={w0}): there is no #pre; the precondition is written out.
    • The last steps in the group (EC's algebra, and the eight rewrites of special soundness) are by hand; special soundness finds the witness through loge, where EC rewrites with expM, expB, mulcV, ….
