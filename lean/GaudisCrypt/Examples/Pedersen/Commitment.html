    Generic commitment schemes #

    A transliteration of EasyCrypt's theories/crypto/Commitment.ec (theory CommitmentProtocol) into the Gaudí module/procedure syntax.

    • EC's abstract theory types value, message, commitment, openingkey become the fields of the structure CommitmentTypes, declared here as a section variable (types : CommitmentTypes) and hence a Lean parameter of every moduletype and module below that mentions one of them.
    • EC module types become moduletypes.
    • EC's parameterized modules (Correctness(S), HidingExperiment(S,U), BindingExperiment(S,B)) become module X … using (P : T) { … } declarations: the calls are written against the parameters' own fields and the holes are inferred from them.
