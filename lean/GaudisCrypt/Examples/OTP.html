    One-time pad: perfect secrecy against any adversary #

    The adversary picks a message m, sees a ciphertext and guesses a bit. In the real game the ciphertext is m + k for a fresh uniform key k; in the ideal game it is uniform, independent of m. The two games are equivalent for every adversary (real_ideal), so the adversary's guess has the same distribution in both (real_ideal_Pr).

    Not an EasyCrypt file; written as one would be:

    type msg.                        (* a finite group, written additively *)

module type Adversary = {
  proc choose() : msg
  proc guess(c : msg) : bool
}.

module Real(A : Adversary) = {
  proc main() : bool = {
    var m, k, c, b;
    m <@ A.choose();
    k <$ dmsg;
    c <- m + k;
    b <@ A.guess(c);
    return b;
  }
}.

module Ideal(A : Adversary) = {
  proc main() : bool = {
    var m, c, b;
    m <@ A.choose();
    c <$ dmsg;
    b <@ A.guess(c);
    return b;
  }
}.

section.
declare module A <: Adversary.

equiv real_ideal : Real(A).main ~ Ideal(A).main : ={glob A} ==> ={res, glob A}.
proof.
proc.
call (_ : true); wp.
rnd (fun k => m{1} + k) (fun c => c - m{1}).
call (_ : true).
by auto.
qed.

lemma real_ideal_Pr &m :
  Pr[Real(A).main() @ &m : res] = Pr[Ideal(A).main() @ &m : res].
proof. by byequiv real_ideal. qed.
end section.

    No assumption on the adversary: its procedures run on their own locals and globals, and the games' variables that differ (k, c) are local to main.
