    Von Neumann's trick (EasyCrypt examples/vonNeumann.eca) #

    EC: "In this theory, we illustrate some reasoning on distributions on Von Neumann's trick to simulate a fair coin toss using only a biased coin (of unknown bias)." Two flips of the biased coin are repeated until they differ, and the first is returned: Simulate.sample returns each bit with the probability of a fair coin (Simulate_is_Fair).

    EC's file, declaration by declaration and script line by line. All of EC's lemmas are proven.

    Translation:

    • op p : { real | 0%r < p < 1%r } as in01_p is the class Params; clone import FixedBiased as Biased with op p <- p is a clone of Lib/EC/DBoolBiased.lean.
    • duniform, duniform1E, duniformE are Lib/EC/DUniform.lean; b2r (a <> b) is if a ≠ b then 1 else 0, b2i (b = b') is if §b = §b' then 1 else 0, pred1 x \o fst is pred1 x ∘ Prod.fst.
    • pHL's bounds are reals, as EC's.

    Gap list (what keeps the file from reading as EC's):

    • GAP 1: EC's equiv SamplePair is SamplePair_Fair (a module and a lemma cannot share a name).
    • GAP 2: bypr (res{1}) (res{2})=> // &1 &2 b0 introduces the arguments and the memories (intro a1 m1 a2 m2 b0 _); EC's have ->: Pr[Fair.sample() @ &2 : res = b0] = 1%r/2%r is a have used by transitivity (the goal's Pr is about the argument a2, a variable, until cases).
    • GAP 3: byphoare (: True ==> _) for EC's byphoare (_: true ==> res = x)=> // (the postcondition is the event's); conseq (: _: = e) is phoare_conseq (: _ ==> _ : = e).
    • GAP 4: vn_fst (mu dvn (pred1 x ∘ Prod.fst) = 1/2) is stated once; EC rewrites vnE and counts at its two uses.
    • GAP 5: after rnd E; auto the goals mu d E = … ∧ ∀ v ∈ d, … are smt_close [mu_pred1, pred1E], with dbiased1E where EC has rewrite dbiasedE; three of them (rnd (pred1 (!x)); auto=> /#, a case analysis on booleans) and the conditions of three conseq ih=> /# are by hand, as is the bounds' equation of Simulate_is_Fair (dbiased1E and ring; EC: smt).
    • GAP 6: the rule for while I V k ε has two goals more than EC's (bound_le_one, sat), and rate (0 < 2 p (1 - p)), which EC's => /> leaves in a conjunction; seq 1: b p (1%r - p) (1%r - p) p leaves 0 ≤ pᵢ (nonneg) when positivity does not find it.
