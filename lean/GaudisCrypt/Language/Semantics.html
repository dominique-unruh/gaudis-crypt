                            class GaudisCrypt.AsGetter (T : Type) (a s : outParam Type) :
                            Type

                            ProgramDenotation.get/ProgramDenotation.set accept anything that forgets to a Getter/Setter — a Getter/Setter itself, or a full Lens/Variable. The value/state types are outParams recovered from the argument, which sidesteps the Lean 4.30 coercion that no longer fires when the value type is a metavariable.
