    Footprint-disjointness does not frame a run #

    A run confined to a footprint R need not leave the content (touched_getter) of a region F ≤ Rᶜ unchanged: with qKer's lazy flip (IndistinguishableVsGlob), the program qProg lies in R = Footprint.from {qKer} and moves false to true with probability ½, which F = qCentralizer = Rᶜ separates. F has no reset (qCentralizer_not_hasReset); for regions with a reset (lens regions) the frame holds (Lib.RO.Instantiate.inFootprint_preserves_touched).

    This is why a one-sided run of an abstract procedure (EC's call{1}) can be framed against a lens region, or a granular cover (Logic/Granular.lean), but not against an arbitrary FVP.fvP A from footprint-disjointness alone (notes/SHA3/GlobGranularity.md).
